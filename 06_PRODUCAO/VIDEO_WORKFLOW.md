# Pipeline de vídeo

`idea` → `triage` → `research` → `fact_check` → `script_draft` → `script_review` → `storyboard` → `asset_rights` → `production` → `final_audit` → `ready_to_publish` → `published` → `analysis`

Cada transição precisa de critérios de entrada e saída. Falhas retornam à etapa responsável. Aprovações vinculam-se a versões específicas. Etapas críticas não podem ser puladas por comando genérico.
